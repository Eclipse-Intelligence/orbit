Orbit is Eclipse's in-house CRM: Next.js 16 (App Router, React 19, Tailwind v4) on Postgres with row-level security, hosted on Vercel and Supabase. Read `CONVENTIONS.md` before changing code, `README.md` for setup, features and environment variables, and `docs/architecture.md` for how the pieces fit together. `docs/api.md` and `docs/mcp.md` describe the agent API and MCP server, and `docs/assistant.md` describes the in-app assistant and every one of its tools.
